# Station

Un métier sur le plan. Remplissage `cat-<categorie>` (sinon `ligne-<id>`), liseré `surface` de 2 px pour rester lisible sur le pastel du quartier.

- **Métier d'entrée** : station pleine. **Métier d'évolution** : station à anneau, comme une correspondance.
- États : `repos`, `survol` (station grandie + halo de sa couleur, liens « voisin » affichés), `focus` (anneau `focus`), `attenue` (hors du top 3 après le quiz, 45 % d'opacité, **le titre reste lisible** dans l'infobulle et la vue liste).
- Le type se dit aussi en mots dans l'infobulle, la fiche et la liste : la forme n'est qu'un renfort.
