# PlageSalaire

Barre de plage d'une fourchette Silkhom, sur l'**échelle propre à son cartouche** (toutes zones et tous profils confondus, pour que changer de zone ne déplace pas l'échelle). Décorative (`aria-hidden`) : la fourchette est toujours écrite en chiffres à côté. **Jamais d'échelle partagée avec l'Apec.**
