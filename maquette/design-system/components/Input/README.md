# Input

Champ texte toujours accompagné de son `label` visible (jamais de placeholder seul). Props : `label`, `hint`, `error` (texte qui dit comment corriger), `optional`, `icone: 'recherche'`, plus tout attribut d'`input`.

L'erreur passe le contour en `danger` 2 px et ajoute une icône et un message relié par `aria-describedby`.
