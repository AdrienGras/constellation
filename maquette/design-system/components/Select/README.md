# Select

Liste déroulante, `select` natif dans la maquette pour rester accessible partout ; à l'implémentation, `Select` de shadcn/ui (Radix). Props : `label`, `options: [{ value, label }]`, `hint`.

Pour choisir parmi les 68 métiers (cible de la roadmap), utiliser une recherche (`Input` avec `icone: 'recherche'`, puis `Command` de shadcn) plutôt qu'une liste.
