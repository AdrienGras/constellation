# Dialog

Fenêtre modale (`role="dialog"`, `aria-modal`, titre relié). Props : `open`, `title`, `description`, `children`, `footer` (boutons, action principale à droite), `onClose`, `inline` (aperçu sans recouvrir la page). À l'implémentation, `Dialog` de shadcn/ui gère le piège du focus et la touche Échap. Usage : ajout et modification d'un item de roadmap, import JSON.
