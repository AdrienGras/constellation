# Badge

Étiquette courte (un à trois mots) : compétence, code ROME, statut.

- `secondary` par défaut, pour les compétences d'une fiche.
- `outline` pour une méta-donnée (code ROME, type de métier via `BadgeType`).
- `succes`, `attention`, `danger`, `neutre` : un état ; **toujours avec un mot**, l'icône est un renfort.
- Le badge de fiabilité a son composant : `BadgeFiabilite`.

Ne jamais mettre une phrase dans un badge ; ne jamais distinguer deux badges par la couleur seule.
