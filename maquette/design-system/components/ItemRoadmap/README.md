# ItemRoadmap

Un item d'une année de la roadmap. Props : `type` (`projet` / `notion`), `titre`, `url`, `note`, `premier`, `dernier` (désactivent monter / descendre), `onMonter`, `onDescendre`, `onModifier`, `onSupprimer`.

- Le type se lit en mot **et** en icône (code / livre), sur le pastel des lignes 5 et 1.
- Réordonner : poignée pour la souris, **boutons Monter / Descendre** pour le clavier, chacun nommé avec le titre de l'item.
- L'URL s'affiche sans `https://` et passe à la ligne si elle est longue ; à l'impression, elle est écrite en entier.
