# PastilleLigne

La marque d'une ligne (macro-branche), comme un indice de ligne de métro : disque `ligne-<id>` avec son **numéro fixe** (ordre de `macro_branches`, 1 Développement … 8 Management) en `sur-ligne-<id>`, puis le nom.

- Partout où une branche apparaît : légende du plan, en-tête de fiche, résultat du quiz, roadmap.
- `rang: 1 | 2 | 3` ajoute « 1er choix », « 2e choix », « 3e choix » en toutes lettres : le rang **ne remplace jamais** le numéro.
- `sansNom` seulement là où le nom est déjà écrit à côté ; la pastille porte alors un nom accessible.
- Tailles `sm`, par défaut, `lg` (résultat du quiz).
