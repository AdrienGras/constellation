# Table

Tableau de données. Props : `columns: [{ key, label, align?, num? }]`, `rows`, `caption`, `rowHeaders` (première colonne en `th`). Une valeur `null` s'affiche **« n.d. »**, jamais vide ni estimée. `num` aligne les chiffres (mono, tabular-nums). Au-delà de la largeur, le tableau défile dans son cadre.
