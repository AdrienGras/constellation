# Card

Surface blanche (`surface`, `ombre-carte`, `rayon-md`) posée sur `fond`. Sous-composants : `CardHeader`, `CardTitle` (un `h3` par défaut, `as` pour changer de niveau), `CardDescription`, `CardContent`, `CardFooter`.

À réserver aux blocs qui se lisent seuls : une section de fiche, une carte de résultat du quiz, une année de la roadmap. Pas de carte dans une carte ; pas de bordure colorée sur un côté.
